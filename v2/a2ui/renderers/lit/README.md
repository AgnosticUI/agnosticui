# `@agnosticui/a2ui-lit`

Spec-compliant **A2UI `v1.0`** [component catalog](https://github.com/AgnosticUI/agnosticui/blob/master/v2/a2ui/catalog/agnosticui-catalog.json) and Light-DOM Web Component renderer (`<a2ui-surface>`) for AgnosticUI.

## Features

- **25 Curated AgnosticUI Components:** `AgText` + 24 `Ag*` core components (`AgCard`, `AgInput`, `AgCombobox`, `AgMessageBubble`, `AgSelect`, `AgCheckbox`, `AgRadio`, `AgRating`, `AgToggle`, `AgButton`, etc.) rendered in Light DOM so AgnosticUI's **21 runtime skins** and **Light/Dark mode** CSS tokens (`--ag-*`) cascade naturally.
- **Native FACE Validation (`validateSurface`):** Validates Form-Associated Custom Elements (`ElementInternals`) via `reportValidity()` before dispatching `a2uiaction` events.
- **Two-Way `@path` DataModel Sync:** Automatically syncs interactive form inputs back into `@a2ui/web_core`'s `DataModel`.

## Local Development Workflow

All commands below assume you are at the **repository root**:

```bash
# 1. Regenerate catalog wrappers & schema from v2/lib (if v2/lib props changed)
(cd v2/a2ui/catalog && npm run generate)

# 2. Run Vitest unit specs and build dist/ (required before building react/vue renderers)
(cd v2/a2ui/renderers/lit && npm test && npm run build && npm pack)

# 3. Verify zero codegen drift across agnosticui-catalog.json, SKILL.md, and Lit wrappers
(cd v2/a2ui/catalog && npx tsx scripts/check-codegen.ts)
```

> **Note:** Files under `src/components/` and `src/catalog.ts` are generated by `v2/a2ui/catalog/scripts/generate-catalog.ts`. Edit the generator rather than modifying generated wrappers by hand.

## Updating `agnosticui-core` Local Tarball

During monorepo development, `devDependencies` references the local tarball `file:../../../lib/agnosticui-core-2.0.0-alpha.31.tgz`. If you modify components in `v2/lib`:

```bash
(cd v2/lib && npm run build && npm pack)
(cd v2/a2ui/renderers/lit && npm install)
```
